# ji-mesh/public

Umbrella repo for **install scripts, legal docs, logos, public user docs** —
other public repos will be added as submodules.

## Structure

| Path | Content |
| --- | --- |
| `legal/` | Licenses (`LICENSE` = PolyForm Noncommercial 1.0.0), commercial terms of use, upstream MIT notes, published engine ToS research |
| `mandates/` | Published JiMesh company mandates (agent execution rules, metadata, no-mock, schema/architecture rules, workspace rules, …) |
| `AGENTS.md` | **Hard rules for agents: zero secrets / zero PII in this repo** |
